# 🚌 Smart Bus Navigator

A smart bus navigation web application designed to help users explore bus routes and access route information through a simple, user-friendly interface.

## 📌 About the Project

Smart Bus Navigator aims to make bus route information easier to access. The application uses a web-based interface to help users interact with the available bus navigation features.

## ✨ Features

- 🚌 Bus navigation and route information
- 🗺️ Route data managed using JSON
- 💻 Web-based user interface
- 📱 Organized pages and static resources

## 🛠️ Technologies Used

- **Python** — Application logic
- **Flask** — Python web framework (if used by the application)
- **HTML** — Web page structure
- **CSS** — Styling and layout
- **JSON** — Route data storage

## ⚙️ Installation and Setup

### Prerequisites
- Python installed on your computer
- Git installed on your computer

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/VRUSHANK2906/Smart-Bus-Navigator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Smart-Bus-Navigator/smart-bus-navigator-main
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in your terminal.
